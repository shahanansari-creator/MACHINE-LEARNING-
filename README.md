## 🎯 Purpose

This repository is meant to serve as a **one-stop reference** for anyone learning or revising Machine Learning concepts — whether you're:
- Studying ML fundamentals and the math behind it
- Looking for practical, applied coding examples
- Prepping for ML/Data Science interviews
- Searching for your next project idea to build and showcase

## 🗂️ How to Use

1. Start with the **Andrew Ng notes** and **mathematics** PDF if you're new to ML, to build a strong theoretical base.
2. Move to **Applied Machine Learning with Python** and the **ML CookBook** for hands-on implementation.
3. Use the **Cheat Sheet** and **Normalisation vs Standardisation** notes as quick references while working on problems.
4. Browse **600 ML Projects** for project ideas to apply what you've learned.
5. Review **Interview Questions** before applying for ML/Data Science roles.
